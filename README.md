# Нейрореалити — лендинг эфира

Статическая страница: `neuroreality.html`.

## Локальный просмотр

```bash
open neuroreality.html
```

или любой локальный сервер, например:

```bash
python3 -m http.server 8080
```

и открыть http://localhost:8080/neuroreality.html

## Файлы

| Файл | Назначение |
|------|------------|
| `neuroreality.html` | Вёрстка, стили, скрипты лендинга |
| `hero.jpg` | Герой-баннер |
| `dasha.png` | Карточка героя в блоке канала |
| `design-md/STRUCTURE-EFIR-LANDING.md` | Структура и копирайт (референс) |
